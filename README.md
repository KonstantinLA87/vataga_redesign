# Vataga — личный кабинет (вёрстка для правки стилей)

Статическая вёрстка страницы «Фьючерсы» на Vue 3 + Vite. Данные тестовые, со скриншота.

## Запуск
```bash
npm install
npm run dev      # откроется на http://localhost:5173
```

## Где что править
- `src/styles/variables.css` — **все цвета, шрифты, отступы и скругления**. Начинай отсюда.
- `src/styles/base.css` — общие кнопки, бейджи Long/Short/Sell, цвета PnL.
- `src/components/` — блоки страницы, у каждого свои стили внутри `<style scoped>`:
  - `AppHeader.vue` — верхняя шапка
  - `AppSidebar.vue` — левый сайдбар (баннер, биржи, балансы, меню, подписка, «Выйти»)
  - `PnlCard.vue` — карточка суточного PnL
  - `TransferCard.vue` — блок переводов
  - `DataTable.vue` — таблицы «Открытые позиции» и «Заявки»
  - `Icon.vue` — иконки
- `src/data/mock.js` — тестовые данные (позиции, заявки, балансы).
